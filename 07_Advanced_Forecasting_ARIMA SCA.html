# ARIMA Evaluation
from sklearn.metrics import mean_absolute_error, mean_squared_error
import numpy as np

arima_mae = mean_absolute_error(
    arima_forecast_df["Total_Demand"],
    arima_forecast_df["ARIMA_Forecast"]
)

arima_rmse = np.sqrt(
    mean_squared_error(
        arima_forecast_df["Total_Demand"],
        arima_forecast_df["ARIMA_Forecast"]
    )
)

arima_mape = np.mean(
    np.abs(
        (arima_forecast_df["Total_Demand"] -
         arima_forecast_df["ARIMA_Forecast"])
        / arima_forecast_df["Total_Demand"]
    )
) * 100

print("ARIMA Model Evaluation")
print("=" * 55)
print(f"MAE  : {arima_mae:.2f}")
print(f"RMSE : {arima_rmse:.2f}")
print(f"MAPE : {arima_mape:.2f}%")

Demand Forecasting & Model Evaluation¶

Objective¶

The objective of this phase was to build and evaluate demand forecasting models using the feature-engineered supply chain dataset and select the best-performing model based on forecasting accuracy metrics.

Work Completed¶

1. Feature-Engineered Dataset Loading¶

  • Loaded the final feature-engineered dataset.
  • Dataset Shape: 83,750 rows × 33 columns.
  • Date Range: 31-Jan-2024 to 30-Dec-2024.
  • Verified missing values and duplicate records.

2. Daily Demand Aggregation¶

  • Aggregated Units_Sold at daily level to create Total_Demand.
  • Created a daily demand time series containing 335 observations.

3. Chronological Train-Test Split¶

  • Applied a time-based train-test split to avoid data leakage.
  • Training Set: 268 observations.
  • Testing Set: 67 observations.
  • Train Period: 31-Jan-2024 to 24-Oct-2024.
  • Test Period: 25-Oct-2024 to 30-Dec-2024.
  • Verified that there was no date overlap.

4. Baseline Forecasting¶

Two Moving Average forecasting models were developed:

  • 7-Day Moving Average
  • 30-Day Moving Average

Model evaluation:

Model MAE RMSE MAPE
7-Day Moving Average 147.29 169.11 3.93%
30-Day Moving Average 476.63 505.14 12.47%

The 7-Day Moving Average was selected as the best baseline model.

5. ARIMA Forecasting¶

  • Developed an ARIMA(1,1,1) model.
  • Training observations: 268.
  • Generated forecasts for the complete 67-day test period.
  • Evaluated ARIMA using MAE, RMSE and MAPE.

ARIMA Performance:

  • MAE: 1053.89
  • RMSE: 1264.51
  • MAPE: 25.74%

6. Forecasting Model Comparison¶

All forecasting models were compared using the same test dataset.

Model MAE RMSE MAPE
7-Day Moving Average 147.29 169.11 3.93%
30-Day Moving Average 476.63 505.14 12.47%
ARIMA(1,1,1) 1053.89 1264.51 25.74%

Final Model Selection¶

The 7-Day Moving Average was selected as the best forecasting model because it achieved the lowest RMSE, MAE and MAPE.

7. 90-Day Demand Forecast¶

Using the selected 7-Day Moving Average model, a recursive 90-day demand forecast was generated.

Forecast Period:

  • Start: 31-Dec-2024
  • End: 30-Mar-2025
  • Forecast Horizon: 90 days

Forecast Insights:

  • Average Forecasted Demand: 4,943.11 units/day
  • Minimum Forecast: 4,906.86 units/day
  • Maximum Forecast: 4,953.76 units/day
  • First 7-Day Average: 4,936.32
  • Last 7-Day Average: 4,943.79

The forecast indicates relatively stable demand over the next 90 days.

8. Forecast Validation & Output¶

  • Forecast Rows: 90
  • Missing Values: 0
  • Duplicate Rows: 0
  • Final 90-day forecast was successfully saved as a processed CSV file.

Key Business Insight¶

The 7-Day Moving Average provided the most accurate demand forecasts for this dataset, outperforming both the 30-Day Moving Average and ARIMA(1,1,1). The 90-day forecast indicates relatively stable future demand, which can support inventory planning, procurement decisions and supply chain resource allocation.
